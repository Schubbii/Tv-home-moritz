# TCL C7K, older EU firmware: Android 12, STT2.221228.001 (device G08, model "Smart TV Pro", MediaTek)
# For this build ONLY. A C7K on Android 14 (UTT2.250416.001) uses debloat.txt in this folder.
# Check with: tools/tv.py --probe  ->  ro.build.version.sdk = 31 and ro.build.display.id = STT2.221228.001
#
# Built from the tested CleanYourTV list for this build, examples/tcl-g08-eu-android12 (five units, among
# them a 55C7K on STT2.221228.001 with the launcher as Home), keeping only the low-risk part.
#   https://github.com/Gathin23/cleanyourtv/tree/main/examples/tcl-g08-eu-android12
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh tcl-c7k/debloat-android12.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh tcl-c7k/debloat-android12.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Packages that are not on the TV are simply skipped.
#
# DO NOT DISABLE on this build (verified on real sets, see the list linked above):
#   com.tcl.suspension  - source panel of the remote's Input key (key goes dead without it)
#   com.tcl.interactive - TIAS service com.tcl.tv binds for the source/HbbTV overlay (error spam at ~10 Hz)
#   com.tcl.ttvs        - same TIAS chain, teletext keyboard; also the firmware updater
#   com.tcl.autopair    - Bluetooth remote pairing (a remote that unpairs could never pair again)
#   com.tcl.guard       - disabled, the system retries its service every 5 seconds
#   com.tcl.tv, com.tcl.tvinput, com.tcl.globalkeyoverlay, com.dolby.*, Play Store, Play Services
